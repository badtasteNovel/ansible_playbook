## 📦 安裝指南 (Installation)

請先確保您的本機環境已安裝 **Node.js (>= 18.0.0)**。

1. **Clone 專案**
   ```bash
   git clone https://github.com
   cd 專案名稱
   ```

2. **安裝相依套件**
   ```bash
   npm install
   ```

3. **設定環境變數**
   複製範例設定檔並填入你的參數：
   ```bash
   cp .env.example .env
   ```
